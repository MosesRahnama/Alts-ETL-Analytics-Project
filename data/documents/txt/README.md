# Page-aligned text

Page-aligned text derived from the source PDFs for search and quotation.

| File | Role |
|---|---|
| `MANIFEST.csv` | One row per source PDF: pages read by pdfplumber, pages read by RapidOCR, empty pages, character count, seconds, and any error. |
| `*.txt` (442 files) | Page-aligned source text regenerated from the PDF corpus. |
