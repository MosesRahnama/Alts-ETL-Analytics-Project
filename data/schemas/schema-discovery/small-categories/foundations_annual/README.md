# Foundations_Annual field survey

Field survey of the Foundations_Annual family: file ledger, field ledger, source-backed sample, and schema note.

| File | Role |
|---|---|
| `foundations_annual.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `foundations_annual.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `foundations_annual.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `foundations_annual.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
