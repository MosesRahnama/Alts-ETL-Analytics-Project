# Stewardship_Proxy_Report field survey

Field survey of the Stewardship_Proxy_Report family: file ledger, field ledger, source-backed sample, and schema note.

| File | Role |
|---|---|
| `Stewardship_Proxy_Report.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `Stewardship_Proxy_Report.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `Stewardship_Proxy_Report.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `Stewardship_Proxy_Report.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
