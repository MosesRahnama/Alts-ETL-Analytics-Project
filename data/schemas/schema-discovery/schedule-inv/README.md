# Schedule_Inv field survey

Field survey of the Schedule_Inv family: schedules of investments listing each portfolio holding with cost and fair value.

| File | Role |
|---|---|
| `schedule_inv.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `schedule_inv.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `schedule_inv.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `schedule_inv.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
