# Pricing outputs

| File | Content |
|---|---|
| `positions.csv` | Ask economics, buyer ceilings, returns, funding, and decision states by scenario. |
| `cashflows.csv` | Future buyer cash flows used by the pricing calculations. |
| `forecast-steps.csv` | Quarterly NAV, funding, growth, and distribution reconciliation. |
| `sensitivities.csv` | Buyer-ceiling sensitivity to the required annual return. |
| `portfolios.csv` | Portfolio economics recomputed from dated position cash flows. |
| `decisions.csv` | One disposition per position and scenario. |
| `exceptions.csv` | Calculation warnings and blocked positions. |
| `market-comparison.csv` | Held-out predictions for the separate fictional-market experiment. |
