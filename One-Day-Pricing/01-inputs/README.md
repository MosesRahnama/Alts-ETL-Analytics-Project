# Pricing inputs

| File | Content |
|---|---|
| `positions.csv` | Selected hypothetical seller positions and transferred balances. |
| `interim-events.csv` | Reference-to-closing calls and distributions, with actual or forecast status. |
| `assumptions.csv` | Declared transaction and forecast settings. |
| `evidence.json` | Parent records, field origins, synthetic events, and evidence references. |
| `manifest.json` | Input, code, policy, population, and parent-state fingerprints. |
| `trades.csv` | Separate fictional secondary transactions used only by the market-model experiment. |
