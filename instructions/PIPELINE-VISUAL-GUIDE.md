# Pipeline reference

| Stage | Input | Output and control |
|---|---|---|
| Extraction | PDF, page text, images, and table aids | Independent A/B candidates and page coverage |
| Review | Candidates, comparison, and native pages | Resolution records and validated final evidence |
| Corrections | Source-backed correction matrix | Revised resolution and final files; original proposals retained |
| Normalization | Published evidence and decision matrices | Typed observations, stable identities, and supported fund attributes |
| Promotion | Typed facts with units, scope, and dates | Source-only fund tables; incompatible meanings refused |
| Completion | Source-only snapshot and declared parameters | Labelled generated rows and imputed cells on the same fund IDs |
| Quality and analysis | Separate source and completed populations | Accounting checks, metrics, market comparisons, and allocations |
| Publication | Current reviewer tables | CSV/database parity, page references, and dashboard |
