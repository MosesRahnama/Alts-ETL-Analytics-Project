# Cash_Flow_Notice field survey

Field survey of the Cash_Flow_Notice family: file ledger, field ledger, source-backed sample, and schema note.

| File | Role |
|---|---|
| `cash_flow_notice.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `cash_flow_notice.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `cash_flow_notice.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `cash_flow_notice.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
