# Quarterly_Report field survey

Field survey of the Quarterly_Report family: periodic partner reports carrying performance, economics, and portfolio sections.

| File | Role |
|---|---|
| `quarterly_report.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `quarterly_report.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `quarterly_report.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `quarterly_report.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
