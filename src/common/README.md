# Common

Shared financial mathematics and decision-matrix access.

| File | Role |
|---|---|
| `__init__.py` | Package marker so Python can import the modules in this folder. |
| `finance.py` | Calculate XNPV and XIRR with dated cash flows. |
| `matrices.py` | Validate and read decision matrices, separate shared contexts, reject absent lookups, and write the stage-20 check record. |
