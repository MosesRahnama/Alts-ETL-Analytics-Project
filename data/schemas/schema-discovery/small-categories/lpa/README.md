# LPA field survey

Field survey of the LPA family: file ledger, field ledger, source-backed sample, and schema note.

| File | Role |
|---|---|
| `lpa.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `lpa.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `lpa.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `lpa.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
