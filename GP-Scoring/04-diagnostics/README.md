# V2 diagnostics

| File | Content |
|---|---|
| fund-diagnostics.csv | One row per supplied fund: returns, capital recovery, benchmark wealth, concentrations, terms and missing-value reasons. |
| manager-diagnostics.csv | One row per manager and strategy: score contributions, benchmark counts, history status and averages. |
| cohort-membership.csv | The funds used in each comparison. |
| genealogy.csv | Fund ordering within each manager and strategy. |
| coverage.csv | Availability decisions by fund and measure. |
| evidence-readiness.csv | Supported and required field counts by review dimension. |
| decisions.csv | Input exclusions and their reasons. |
| evidence.json | Calculation inputs and dates, benchmark cash flows, case investment gains, operating scenarios and source references. |
| manifest.json | Input files, policy and implementation used by this build. |
