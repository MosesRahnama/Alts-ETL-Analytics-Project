# Two-fund example

A clean fund and a damaged fund in the fund-model layout expose the financial calculations and rule outcomes.

| File | Content |
|---|---|
| `synthetic_parameters.csv` | The parameter set the two funds were generated from |
| `fund_master.csv` | The two funds |
| `fund_periods.csv` | Their periods |
| `fund_cashflows.csv` | Their dated flows |
| `defect_injections.csv` | The defects planted in the damaged fund |
| `quality_results.csv` | Rule results, with the planted defects caught |
