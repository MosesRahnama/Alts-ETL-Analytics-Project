# Side_Letter field survey

Field survey of the Side_Letter family: file ledger, field ledger, source-backed sample, and schema note.

| File | Role |
|---|---|
| `side_letter.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `side_letter.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `side_letter.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `side_letter.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
