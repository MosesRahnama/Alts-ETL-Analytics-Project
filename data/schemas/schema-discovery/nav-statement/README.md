# NAV_Statement field survey

Field survey of the NAV_Statement family: net asset value statements and their roll-forward lines.

| File | Role |
|---|---|
| `nav_statement.file-ledger.csv` | One row per reviewed source document with the pages read, the fields found, and the disposition. |
| `nav_statement.field-ledger.csv` | One row per visible source field with grain, location, prevalence, and mapping decision. |
| `nav_statement.sample.csv` | Source-backed sample rows that tested the field contract before it was frozen. |
| `nav_statement.schema.md` | Schema note for the family: record grains, fields, and document prevalence from the ledger. |
