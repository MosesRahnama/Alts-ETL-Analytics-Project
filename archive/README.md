# Archive

Large content-addressed backups live outside the public repository in sibling folder `Alts-ETL-Analytics-Project-Artifact-Archive`; `ALTS_ARTIFACT_ARCHIVE` overrides that location. The repository retains the readable hash and command ledger at `ledgers/pipeline/transformation-receipts.csv`.

Run `python -m src.pipeline.transformation_lineage` for the optional full backup check.
